You are a senior SEO engineer, UX designer, and frontend developer.

Your task is to upgrade the website https://born.directory so that it performs well for:

1. Search engine crawling
2. Semantic HTML structure
3. Nielsen usability heuristics
4. Information clarity and navigation

The current website is extremely minimal and fails heuristic analysis tools because it lacks semantic HTML elements such as navigation, headings, forms, and structured sections.

Your objective is to restructure the page so that it is both SEO-friendly and user-friendly while preserving the minimalist aesthetic.

--------------------------------
CORE SEO REQUIREMENTS
--------------------------------

Ensure the page contains crawlable semantic structure:

<header>
<nav>
<main>
<section>
<footer>

Implement a strong heading hierarchy:

h1: page purpose
h2: major sections
h3: subsections

Example structure:

<h1>Born — Startup Directory for Builders</h1>

<h2>Explore New Startups</h2>

<h2>Featured Builders</h2>

<h2>Submit Your Startup</h2>

Search engines must clearly understand:
• what the site is
• what content exists
• what pages can be navigated

--------------------------------
NAVIGATION
--------------------------------

Add a clear global navigation menu.

Include:

Home
Directory
Startups
Builders
Submit
About

Navigation should be accessible and visible on every page.

Example:

<nav>
  <a href="/">Home</a>
  <a href="/directory">Directory</a>
  <a href="/builders">Builders</a>
  <a href="/submit">Submit Startup</a>
</nav>

--------------------------------
HERO SECTION
--------------------------------

Create a clear hero section that explains the product immediately.

Example structure:

<h1>Discover New Builders and Startups</h1>
<p>Born is a curated directory of founders, builders, and emerging products.</p>

Add a primary CTA:

<button>Explore Directory</button>

--------------------------------
CONTENT SECTIONS
--------------------------------

Add structured sections that create crawlable content:

<section>
<h2>Latest Startups</h2>
</section>

<section>
<h2>Featured Builders</h2>
</section>

<section>
<h2>Recently Added Products</h2>
</section>

Each section should contain internal links so search engines can crawl deeper pages.

--------------------------------
INTERNAL LINKING
--------------------------------

Every major section must contain crawlable links.

Example:

<a href="/startup/xyz">XYZ Startup</a>

Search engines should be able to navigate the site entirely via links.

--------------------------------
FOOTER
--------------------------------

Add a footer containing:

Contact
About
Submit Startup
Privacy Policy
Terms

Example:

<footer>
<a href="/about">About</a>
<a href="/contact">Contact</a>
<a href="/submit">Submit</a>
</footer>

--------------------------------
SCHEMA MARKUP
--------------------------------

Add structured data where appropriate.

Use schema types such as:

Organization
WebSite
ItemList

--------------------------------
PERFORMANCE + SEO
--------------------------------

Ensure the page:

• renders crawlable HTML
• does not rely solely on client-side rendering
• includes meta title and description
• includes alt attributes on images
• includes OpenGraph tags

Example:

<meta name="description" content="Discover startups and builders on Born, a curated directory for new products.">

--------------------------------
ACCESSIBILITY
--------------------------------

Ensure accessibility improvements:

• aria labels where appropriate
• keyboard navigation support
• focus states on links and buttons

--------------------------------
OUTPUT REQUIREMENTS
--------------------------------

1. Analyze the current site structure
2. Identify missing SEO and UX elements
3. Implement the improved HTML structure
4. Maintain minimal design but introduce clear hierarchy
5. Ensure the site becomes crawlable and understandable

The final result should:

• clearly communicate the site's purpose
• allow users to navigate easily
• expose content to search engines
• pass heuristic UX analysis tools
